# 百米45秒实验记录

本次已得到可加载的 **44.966667秒 / 100.1米** 模型。方法是原有PPO训练，再对动作输出偏置做小幅参数搜索。纯PPO保存快照的最好成绩为45.700001秒。本次未修改物理后端、赛道长度、游戏计时和原有终止规则。

这份文件记录本次实验的奖励、参数、权重出处和验证结果，便于与此前50秒版本比较。本版本保存代码、精选速度版权重、回放及训练配置。

## 保存结果

- 速度版权重：`checkpoints/ppo_classic100m_under45.pt`。
- 速度版回放：`replays/classic_100m_under45_44p97.bin`，1349个动作。
- 姿态候选权重：`checkpoints/ppo_classic100m_target45_pose.pt`，47.833332秒。
- 获胜PPO训练配置：`configs/ppo_target45_v28_confident.json`。
- 归档权重续训配置：`configs/ppo_under45_resume.json`，从速度版开始并将新结果另存，不覆盖归档权重。
- 验证记录位于项目上一级的 `verification/target45_under45_*.json`。

权重和回放通常被原有 `.gitignore` 忽略。本版本仅将44.97秒精选权重和对应回放显式加入Git；其他实验快照、日志和姿态候选保留在本地。获胜训练配置需要本地的初始权重；干净检出后可用归档权重续训配置。

## 实测结果与限制

| 指标 | 旧49.97秒模型 | 47.83秒姿态候选 | 44.97秒速度版 |
|---|---:|---:|---:|
| 完赛时间（游戏秒） | 49.966667 | 47.833332 | 44.966667 |
| 已确认交替脚落地次数/秒 | 1.0007 | 1.1673 | 0.9758 |
| 平均前倾角（头部到躯干几何代理） | 3.75° | 2.39° | 0.47° |
| 距5°的平均绝对误差 | 4.18° | 4.09° | 5.26° |
| 躯干高度标准差/初始站立高度 | 2.03% | 2.52% | 4.84% |

姿态统计从第5个游戏秒开始，包含其后完整回合。高度指标是躯干代理，不是按各部件质量计算的重心。物理接口没有膝盖触地标志，低姿态比例为0不能证明每一帧膝盖都未触地。

速度版在相同初始状态的16次确定性复跑中全部完成，全部为44.966667秒。这证明保存、加载及并行执行可复现该成绩，不能当作16种不同初始条件的泛化测试。

速度版随机采样测试：64次有56次完成，成功回合平均48.921429秒，最快45.566666秒，0次低于45秒。因此，目前达成的是确定性成绩低于45秒，尚未达成随机运行也稳定低于45秒、持续约5°前倾和更小的身体起伏。

## 修改的代码及影响

### `src/reward_profiles.cpp`、`src/reward_profiles.h`

- 将前倾目标设为5°，保留软容差。向前且有脚支撑时给予姿态进度奖励；起步2秒后，对偏离目标较大的姿态增加按时间计算的软惩罚，飞行阶段也计算。
- 用0.6秒指数平滑的躯干高度作为参考。偏离超过初始站立高度的2%才开始处罚，允许小幅自然摆动；未使用“禁止上下运动”的硬约束。
- 增加交替脚落地奖励：先离地至少0.1秒，再触地至少2帧，左右交替且间隔至少0.15秒。只有直立、向前取得新进度且近期速度至少1.5米/秒才奖励。原地踏步、触地抖动、失败状态均不能领取此项奖励。
- 交替落地目标1.4次/秒，最终每米奖励系数2.4；奖励由实际新进度限制，不能靠反复踏步累积。
- 速度目标由2.2提高到2.5米/秒，快速完赛奖励目标由48改为43秒，给45秒目标保留余量。
- 保留此前低姿态、后仰、失败、起步与进度的规则。所有新增状态在reset时清零。

加大奖励系数本身没有直接保证更高步频；实测最快模型仍以更大的有效前进量取得成绩，因此保留了姿态候选作比较。

### `scripts/train_ppo.py`

- 增加可选熵系数调度及日志。探索阶段测试过0.06逐步降至0.01；获胜巩固训练使用0.005降至0.001。
- 增加可选的12个部件转动速度特征：从相邻两帧角度和游戏时间推导，处理角度跨越±π及reset时零时间差，限幅±20弧度/游戏秒，再除以10。
- 新特征经零初始化线性投影加入原MLP第一层，开始时保持旧策略输出完全一致。原始环境68维观测、16个离散动作和rollout存储格式均保留。
- 保存权重包含新投影；加载时自动恢复。优化器在模型完整恢复之后创建，确保新参数进入优化器。
- 沿用原PPO-Clip、GAE、共享Actor/Critic、日志与保存流程。

### `scripts/distill_policy.py`

仅调整加载后创建优化器的顺序，并保存新特征配置，使原有蒸馏流程也能恢复和优化新特征。没有用蒸馏产生最终45秒模型。

## 获胜训练参数

| 参数 | 数值 |
|---|---:|
| 并行环境 / 环境线程 | 128 / 16 |
| rollout长度 / 每批样本 | 256 / 32768 |
| epochs / minibatches | 4 / 8 |
| 学习率 | 1e-5 |
| gamma / GAE lambda | 0.995 / 0.98 |
| PPO clip / target KL | 0.2 / 0.015 |
| value loss系数 | 0.01 |
| 熵系数 | 0.005 → 0.001，前512次update线性衰减 |
| 隐藏层 / 历史帧 | 256、256 / 32 |
| 固定观测归一化 / 转动速度特征 | 开启 / 开启 |
| 本轮updates / 保存间隔 | 2048 / 16 |
| 随机种子 | 445 |

网络从已有权重逐步扩展，初始输出经过一致性验证。降低value loss系数的依据是实际rollout中的梯度测量：原0.05设置下，价值损失对共享网络的梯度约为策略梯度的3.62倍；0.01对应约0.72倍。这是一批数据的诊断，不能视为所有阶段的固定比例。

32帧提供约1秒动作历史。128个环境用于降低采样波动；小学习率和KL保护限制续训对已学步态的破坏。探索与巩固采用不同随机性，避免始终用大量随机按键扰乱已经筛出的快跑策略。

## 最终权重出处

1. 使用上述配置完成PPO训练，纯PPO最好快照为 `ppo_target45_v28_confident_update_010832.pt`，45.700001秒。
2. 最终参数搜索从另一份可完赛快照 `ppo_target45_v28_confident_update_010656.pt` 出发，基准45.966667秒。
3. 评估2048组小幅Actor偏置扰动，种子94542，noise scale为0.05；候选466完成44.966667秒。
4. 将该候选保存为 `ppo_classic100m_under45.pt`，在 `under45_refinement` 中记录来源、扰动、方法和评估结果。
5. 参数搜索后重建空状态Adam，避免使用与新偏置不对应的旧优化器动量。权重逐项验证与获胜候选相等。

这属于“PPO训练 + 小幅策略参数搜索”，不是仅靠PPO更新得到44.97秒。参数搜索不改变物理、观测、计时、动作含义或终止规则；播放及评估直接使用已保存模型输出，没有起步动作脚本。

## 验证与未采用的方向

- 原生奖励行为测试通过：起步奖励一次性领取、低姿态限制、5°软目标、上下起伏、交替脚落地、原地踏步与抖动过滤。
- 新特征测试通过：旧模型输出逐项相同、角速度单位、跨角边界、reset、非零梯度、严格保存加载及恢复旧权重。
- 4个环境、512步的小训练通过。最终权重也已实际加载并续训512步、再次保存；该加载测试使用1e-6学习率及1个epoch，避免把大批量训练的更新参数直接套到极小批量。
- 作者导出程序生成1349帧回放；重新读取并执行所有动作，最后一帧成功完成100.1米。游戏计时与1349/30一致。
- 完成确定性及随机评估，观测、动作与奖励未发现NaN/Inf。
- 更大的固定熵、单纯增大步频奖励、固定共享网络、GAE lambda=1.0等方向未带来更好的最终成绩。固定共享网络的实验开关已撤回。
- 单段及3841组两段短起步动作诊断未改善成绩，未使用起步脚本或动作模仿绕过训练。

下一阶段应把保持45秒内速度与姿态指标一起纳入模型选择，并改善随机运行的成功率。当前44.97秒仅比45秒快1帧，余量很小。
