# 前倾姿态与提速：代码修改及重训结果

已完成奖励调整、编译、短训练、续训、最终评估及回放导出。最终模型比上一版更快，明显后仰、低姿态和随机策略摔倒率均下降。原有模型没有覆盖。

## 代码修改

本次在上一提交 `55b0d05` 的基础上，只修改两个受 Git 管理的源文件：35 行新增、3 行删除，尚未创建新的 Git 提交。

- `src/reward_profiles.cpp`：classic_100m 前进奖励整体乘以 1.2；增加微前倾且脚支撑前进的奖励；增加持续明显后仰的分级处罚。原有身体高度奖励、低姿态处罚、终点规则，以及跨栏、跳远奖励保持原样。
- `src/reward_profiles.h`：增加 `backwardLeanTime_`，每次 reset 清零，避免后仰计时跨回合残留。

姿态角度使用头部相对躯干的世界坐标计算：`atan2(头x−躯干x, 躯干y−头y)`。头在躯干正上方为 0°，正值表示向终点方向前倾。它是身体姿态代理，包含头部活动的影响，不把原始躯干角度的 0°误当作直立，也不是膝盖碰撞测量。

新增奖励的具体规则：

1. 身体高度合格时，每米基础前进奖励从 1 变为 1.2；脚支撑时总前进奖励从 2 变为 2.4。仍按新创最高距离发放，往返不能重复领取。
2. 身体高度合格、脚支撑、创造新的前进距离记录时，前倾 5°～10°可再获得最多每米 0.4 分。偏离该范围后奖励线性降低，偏离达到 15°后此项为零。站着前倾没有这项额外奖励，腾空前进保留基础奖励。
3. 较高姿态下，后仰角小于 −10°且持续超过 0.15 秒才处罚；每游戏秒最多 −0.3 分，后仰 −10°到 −30°之间按严重程度线性增加，超过 −30°封顶。恢复姿态不返还处罚，短暂摆动有宽限。

新建 `configs/ppo_foot_running_v4.json` 沿用作者 JSON 配置系统，保留上一版配置作对照；文件按照原 `.gitignore` 被忽略。没有修改 PPO、Actor/Critic、采样缓冲区、观测格式、动作格式、环境结束条件或物理 DLL。

## 训练与验证

先执行实际 C++ 奖励行为测试，验证前倾方向、目标区间、奖励上限、短暂后仰宽限、持续后仰处罚、reset、奖励不重复领取，以及原有防爬行和终点规则；两套测试通过，然后重新编译。

短训练：4 环境、2 线程、每轮采样 128 步，4 轮，新增 2048 条转移。加载上一版最终模型，重置优化器适应新奖励，保留网络权重。

正式续训：RTX 5070 Ti，128 环境、8 线程、每轮采样 256 步，512 轮，新增 16,777,216 条转移。正式轮从短训练检查点续训，保留其优化器状态。学习率从 0.0002 降到 0.0001，让已有步态逐步适应新奖励；其余 PPO 设置保持：4 epochs、8 minibatches、gamma 0.995、GAE lambda 0.95、clip 0.2、entropy 0.01、value 系数 0.5。网络仍为 Tanh MLP 128/128，2 帧输入共 136 维，16 种动作，保存间隔 64 轮。

最终累计 update 1040、global_step 33,562,624。本次新增转移总数为 16,779,264，累计数包含此前训练。正式训练正常完成，实测 238.19 秒，即 3 分 58 秒。

最终权重严格加载、权重有限性、观测 (4,68)、拼接输入 (4,136)、Actor 输出 (4,16)、Critic 输出 (4,)、环境输出、原始回放导出及 CRC/动作范围检查均通过。512 轮训练日志的损失、熵、KL 和 clipfrac 均有限，未发现 NaN/Inf。最终 policy loss −0.0130，value loss 0.4946，KL 0.00298。

## 效果比较

比较使用相同初始环境和相同评估方式。后仰指标从游戏时间第 5 秒开始统计；“明显后仰”指上述姿态代理角度小于 −10°。“低姿态”指躯干高度低于初始站立高度的 80%。

| 固定选择最优动作的回放 | 上一版 v3 | 本轮 v4 |
|---|---:|---:|
| 完成距离 | 100.1 m | 100.2 m |
| 完成时间 | 75.27 s | 65.63 s |
| 明显后仰时间占比 | 35.77% | 6.60% |
| 头在躯干后方的时间占比 | 73.67% | 30.73% |
| 平均姿态代理角度 | −6.86° | +4.80° |
| 低姿态时间占比 | 3.76% | 0.00% |

完成耗时缩短约 12.8%。回放仍有步态摆动和短暂后仰，不能描述为全程固定前倾；低姿态 0%也不等于膝盖零触地。

| 随机策略，种子 20261008，各 64 回合 | 上一版 v3 | 本轮 v4 |
|---|---:|---:|
| 原游戏通关数 | 38/64 | 53/64 |
| 通关回合平均时间 | 76.92 s | 66.80 s |
| 全部回合平均距离 | 76.17 m | 88.69 m |
| 摔倒率 | 40.63% | 17.19% |
| 明显后仰时间占比 | 16.11% | 4.99% |
| 低姿态时间占比 | 4.47% | 1.25% |
| 较高姿态脚支撑时间占比 | 51.35% | 57.70% |

第二个随机种子 20261009，32 回合：25/32 通关，通关回合平均 67.14 秒，明显后仰 5.37%，低姿态 1.51%。这些是本轮观测结果，不代表所有初始姿态或随机种子下都不会摔倒。通关时间只统计通关回合，因此还需要同时看失败率。

评估上一版权重时使用当前同一物理环境与测量方式。奖励规则变化不影响固定权重的动作选择及物理轨迹，但不同奖励版本的 episode return 不能用于解释速度提升；上表比较的是实际距离、时间和姿态。
